# NAVYA
NAVIGATION AUTONOMOUS VEHICLES ON YET - UNSTRUCTURED ASPHALT
NAVYA is an explainable, real-time autonomous driving and adaptive path planning framework engineered specifically for chaotic, lane-free, and unstructured road environments typical of Indian roadways. Standard autonomous vehicle navigation models rely heavily on structured lane markings and predictable traffic rules. On Indian roads, autonomous vehicles face severe challenges such as the absence of clear lane markings and unpaved boundaries, highly heterogeneous traffic including auto-rickshaws, e-rickshaws, stray animals, pedestrians, and children, as well as severe hazards like unmarked speed humps, deep potholes, and construction obstacles. NAVYA resolves these issues by combining real-time object detection with instance segmentation, decision-tree risk classification, dynamic path planning, and SHAP-based model explainability into a unified pipeline.

The system architecture functions as an end-to-end multi-phase pipeline that processes incoming video streams. Camera feed frames are first passed to a computer vision layer powered by YOLOv8 or YOLO11 models for real-time object detection and instance segmentation, which identifies drivable regions, potholes, animals, and vehicles. Next, a risk decision tree evaluates the detected entities based on class priority and proximity to categorize road threats into distinct risk levels ranging from critical to low. The output feeds directly into a dynamic path planner utilizing the Dynamic Window Approach in Python or MATLAB Hybrid A* algorithms to compute safe trajectories around obstacles. An integrated SHAP explainability engine generates interpretable reasoning behind every trajectory decision, and all metrics, telemetry, and visual overlays are rendered live on a Streamlit web interface.

NAVYA incorporates a robust set of features to ensure safe navigation on unstructured roads. The system performs real-time object and hazard detection targeting an mAP@50 score of at least 95 percent across critical road classes. Instance segmentation is leveraged to identify unpaved road edges, dirt shoulders, and drivable paths even when lane markings are completely missing. A dynamic risk hierarchy automatically enforces proportional actions, executing emergency braking for critical threats like children or close pedestrians, hard obstacle avoidance for cows and large potholes, soft path adjustments for rickshaws, and continuous path monitoring for distant objects. The adaptive path planning engine maintains a minimum safety clearance of at least one meter around obstacles with end-to-end processing latency kept under 200 milliseconds. Model transparency is maintained using SHAP explanations to reveal feature contributions for every maneuver, while the Streamlit web app provides live telemetry, risk gauges, and emergency stop overrides.

Setting up NAVYA requires Python 3.10 or higher alongside core machine learning, computer vision, and web deployment libraries. Key dependencies include Ultralytics for YOLO models, OpenCV for video processing, scikit-learn for decision tree risk classification, SHAP for model explainability, Streamlit for dashboard rendering, and NumPy and Pandas for data manipulation. Once dependencies are installed, the user can run predictions using trained NAVYA weights, execute the path planner module, and launch the interactive web dashboard via Streamlit. For advanced simulation and verification, the framework provides full MATLAB integration where users can load occupancy grid maps and execute Hybrid A* path planning scripts within MATLAB or Simulink.
